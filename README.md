# Minesweeper Game

A beautiful, fully functional Minesweeper game that runs directly in your browser!

## Features

- 🎮 **Three Difficulty Levels**
  - Easy: 8x8 grid with 10 mines
  - Medium: 12x12 grid with 30 mines
  - Hard: 16x16 grid with 99 mines

- ⏱️ **Game Timer**: Track how fast you can complete the game

- 🚩 **Flag System**: Right-click to mark suspected mines

- 🎨 **Modern Design**: Beautiful gradient UI with smooth animations

- 📱 **Responsive**: Works perfectly on desktop and mobile devices

## How to Play

1. **Left Click** - Reveal a cell
2. **Right Click** - Place or remove a flag
3. Numbers indicate how many mines are adjacent to that cell
4. Empty cells reveal surrounding cells automatically
5. Win by revealing all non-mine cells
6. Lose if you click on a mine

## Rules

- The first click is always safe - mines are placed after your first move
- Adjacent mine counts help you deduce where mines are located
- Use flags to mark cells you think contain mines
- Complete the board without hitting any mines!

## Controls

- **New Game Button** - Start a fresh game at any time
- **Difficulty Selector** - Switch between difficulty levels
- **Game Modal** - Appears when you win or lose

## Technical Stack

- **HTML5** - Semantic structure
- **CSS3** - Modern styling with gradients, animations, and flexbox
- **Vanilla JavaScript** - Pure game logic with no dependencies

## Getting Started

Simply open `index.html` in your web browser to start playing!

## Browser Compatibility

Works in all modern browsers that support:
- ES6 JavaScript
- CSS Grid
- CSS Gradients
- Flexbox

Enjoy the game! 🎮
